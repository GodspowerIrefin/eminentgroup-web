# eminentgroup-web

Website for Eminent One LLC (People. Care. Opportunities.), a licensed Maryland healthcare staffing agency.

Built with Next.js, React, TypeScript, and Tailwind CSS.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Deploy on Vercel or any host that runs Next.js.

## Content

Company details, services, roles, and open positions live in `lib/site.ts`. Edit that file to update a job listing or contact detail across the site.

The forms compose an email to the office address in the visitor's mail app. They are not connected to a backend or form service yet.
