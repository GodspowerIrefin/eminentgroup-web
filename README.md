# eminentgroup-web

Static website for Eminent One LLC (People. Care. Opportunities.).

Pages: index, About, Services, RegisteredNurse, Employers, JobSeekers, Resources, Contact, Referrals.
Open `index.html` in a browser, or deploy the folder to any static host (Vercel, Netlify, GitHub Pages).

To finish before launch, search the HTML for text in [BRACKETS]: license number, story and vision, owner and team names and photos, hours, pay and benefits, open jobs, testimonials, extra service areas, map.
The forms are not connected yet; they need a form service or backend to send submissions.
