DIRECTION: Mature, editorial, confident. Think premium consultancy, not startup template.

COLOUR
- No pure white pages. Base: warm off-white (#F5F2EB) alternating with
  deep, rich sections (dark green / near-black) so the page has rhythm.
- One accent colour, used only for actions and highlights.
- Subtle film-grain texture on dark sections.

TYPE
- Large serif display headlines (e.g. Fraunces / Instrument Serif),
  clean sans for body (e.g. Inter / Geist).
- Big size contrast: headlines 64–96px desktop, body 17–18px.

LAYOUT
- Asymmetric, editorial grids. Generous white space.
- Full-bleed photography with rounded or masked crops.
- Thin divider lines, small uppercase labels, numbered sections.

ANIMATION (purposeful, never gimmicky)
- Headlines reveal line by line on scroll (mask + slide up, 700–900ms, staggered).
- Images fade and scale from 1.08 to 1 as they enter.
- Numbers/stats count up once when visible.
- Process/timeline line draws itself as you scroll.
- Buttons: smooth fill/arrow-slide hover, 200ms.
- Smooth scrolling (Lenis). GSAP + ScrollTrigger (or Framer Motion if React).
- Only animate transform and opacity. Respect prefers-reduced-motion.

RULES
